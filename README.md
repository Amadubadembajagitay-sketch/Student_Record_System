
# Student Record Management System

## 1. Project Description
The Student Record Management System is a simple Python application that stores and displays student information. It helps users organize student records using object-oriented programming.

## 2. Project Objectives
- To register student information.
- To display student records.
- To store multiple student records.
- To demonstrate object-oriented programming concepts.

## 3. Technologies Used
- Python
- Visual Studio Code
- GitHub

## 4. Features
- Stores student ID, name, and course.
- Displays student details.
- Stores multiple students in a list.
- Counts the total number of students.

## 5. Object-Oriented Programming Concepts
- Classes: Student and StudentManagement.
- Objects: Individual student records.
- Instance method: display_details().
- Class methods: add_student(), display_all_students(), and count_students().
- Data structure: A list is used to store student objects.

## 6. How to Run the Project
1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the command: python main.py

## 8. Conclusion
This project demonstrates how Python classes, objects, methods, and lists can be used to manage student information. It provides a simple foundation for developing more advanced student management systems.


## 9. Digital Public Goods (DPG) Alignment

## 10. Limitations and Future Improvements
This is a beginner demonstration. Future versions could allow users to enter student details, search for students, update records, and save information between runs.
